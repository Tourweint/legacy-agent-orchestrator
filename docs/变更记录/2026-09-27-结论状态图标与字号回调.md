# 2026-09-27 结论状态图标与字号回调

## 起因

用户两条口径：① 之前把状态色从展示层删掉了，现在**只标回结论、不标"思考"**——在最后输出的结果（如"该时段不可用"）处加**对号/错号**，对号代表已预约完成；② 结论字号 22px 太大，稍微调小（不必回到原来那么小）。

## 改动（`frontend/src/components/AnswerBubble.vue`）

- **结论首行加状态图标**（verdict）：
  - `done`（DONE 终态，已办妥）→ **绿色对勾**（IconCheck，`success-500`）；
  - `failed`（如"该时段不可用"）→ **红色错号**（IconX，`danger-500`）；
  - `unsure`（UNRESOLVED）→ **橙色错号**（`warning-500`）；
  - `cancelled`（用户主动停止）→ 不加图标，文字保持浅灰。
  - 图标只出现在结论**首行**（总起句），列表行（`1. …`）不加；不标在"思考"模块上。
- **字号回调**：结论 22px（`text-xl`）→ **18px（`text-lg`）**，移动端 18px → 15px（`text-md`）——比 22 小、比早期 14px 大，居中档。

## 验证

- 前端：`npm test` 10/10、`npm run lint:check`、`npm run build` 通过。
- 浏览器：查询任务（done）——DOM 确认 `.answer.is-done` + 首行前绿色对勾 svg（`rgb(14,159,110)`）真实渲染、6 条预约多行正常；登录失效任务（failed）——红色错号 + "任务异常终止"；结论字号 18px 生效。
