# 2026-09-27 思考与正文间距收紧

## 起因

用户反馈："思考"离下方正文（结论/追问）还是有点远，希望再靠近。

## 改动（`frontend/`）

间距实测构成：思考块底部 `4px` + 消息列表 flex gap `12px`（`--space-3`）+ 答案卡顶部 margin `8px`（`--space-2`）≈ **24px**。

- `src/components/ThinkingBlock.vue`：`.thinking` margin-bottom 改为 `calc(4px - var(--space-3))`（负值抵消 flex gap，净距 4px）；
- `src/components/AnswerBubble.vue`：`.answer` 顶部 margin 归零（`margin: 0 0 var(--space-2)`）。

结果：思考 → 正文净距约 **4px**；用户消息 → 思考仍保持 12px 的正常节奏。

## 验证

- 前端：`npm test` 10/10、`npm run lint:check`、`npm run build` 通过。
- 浏览器端到端：结构化任务终态截图，"思考"底边与结论首行间距约 5px，紧贴。
