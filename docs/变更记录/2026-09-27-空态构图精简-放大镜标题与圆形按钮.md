# 空态构图精简：放大镜标题、圆形发送按钮（2026-09-27）

## 背景

上一轮空态中央构图（问候 → 宽输入框 → 示例）完成后，用户反馈"太居中了，太丑了"，要求精简并调整细节：

1. **发送按钮**：放在输入框右边，做成小圆。
2. **文字**：(a) 删掉"可以这样说（教师）"示例标签，只留下面的例子；(b) 删掉描述"用一句话说明要办的事"（这句已在输入框 placeholder 里，不重复显示）；(c) 标题加逗号："预约教室从这里开始" → "预约教室，从这里开始"。
3. **图标**：放大镜（SVG）放在标题**左边**（同一行），不再竖排在标题上方。

## 改动

1. **`ChatPane.vue`**：
   - hero 里不再用 `EmptyState` 组件（删 import），改为自绘标题行 `.hero-heading`：`IconSearch`（放大镜，22px 淡蓝）+ `<h2 class="hero-title">预约教室，从这里开始</h2>` 横向排列；
   - 描述删除（空态只剩：标题行 → 宽输入框 → 示例 chips，不再有引导说明）；
   - 示例标签"可以这样说（角色）"删除，chips 直接显示；同步删掉不再使用的 `.capability` / `.capability-label` 样式；
   - **垂直重心偏上**：`.hero` 的 `margin: auto` → `margin: 12vh auto auto`（顶部固定留 12vh，其余空间留给底部）——不再钉死在屏幕正中（用户口径"太居中了"），接近 DeepSeek 构图上移手感。水平仍居中。
2. **`Composer.vue`**：发送按钮文字包 `<span class="btn-label">`；hero 形态按钮改为 **40×40 圆形**（`border-radius: 50%`、`padding: 0`、`justify-content: center`、图标 16px、文字 `display: none`、`aria-label`/`title` 保留原文案）；窄屏（<480px）下 hero 圆形按钮不被拉成整条（`width: 40px; align-self: flex-end`）。dock 形态按钮不变（文字 + 图标）。

## 验证

- 前端 `npm test` 10/10、`npm run lint:check`、`npm run build` 全绿。
- 浏览器端到端（空态 DOM/尺寸实测）：标题"预约教室，从这里开始"、放大镜在标题行内、描述与示例标签均不存在、示例 chips 4 条在输入框下方、发送按钮 40×40 圆形且文字隐藏、输入框宽 620px（≈50vw）、hero 顶部在视口 20%（重心偏上）；发消息后 hero 让位、输入框回底部 dock（上轮行为无回归）。

## 尚存说明

- hero 组目前是"标题行 + 输入框 + 示例"三段居中排布；若用户还要更"左对齐/错落"的版式，可再迭代。
- `EmptyState.vue` 组件本身未删（可能仍被其他视图引用），本轮只是 hero 不再使用它。
