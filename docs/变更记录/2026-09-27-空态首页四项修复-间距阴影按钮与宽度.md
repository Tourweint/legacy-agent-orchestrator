# 空态首页四项修复：间距/阴影/按钮圆/宽度与重心（2026-09-27）

## 背景

用户反馈首页（空态 hero 构图）四个问题：
1. "预约教室，从这里开始"离输入框太远；
2. 输入框阴影不匀——上边几乎没阴影、下边重（要求四周变淡或上下统一）；
3. 发送按钮第一次是圆的、第二次对话后变成方的；
4. 输入框太窄；且整体太靠中上，加宽后如仍偏上就再往下挪一点。

## 改动

**`Composer.vue`**：
- **阴影**：`.composer.hero` 的 `box-shadow: var(--shadow-md)`（纯下沉：`0 4px 8px -2px…, 0 2px 4px -2px…`，上边无影）→ 改为**上下对称的均匀淡影** `0 0 18px rgba(16,24,40,0.07)`（边框本身有 1px 细线，阴影只负责"浮起"，四周一致）。
- **宽度**：`min(50vw, 680px)` → **`min(64vw, 780px)`**（用户嫌窄；视口 1239 下实为 780px，接近 dock 的 820 上限，窄屏自动收窄）。
- **按钮圆形统一**：dock 按钮 `border-radius: var(--radius-small)`（6px 方角）→ **`50%`**——dock（32×32）与 hero（40×40）都是圆形，形状不再随对话阶段变化。

**`ChatPane.vue`**：
- **间距**：`.hero-layout` gap `var(--space-4)`（16px）→ `var(--space-2)`（8px），标题贴近输入框；`.hero-chips` 补 `margin-top: var(--space-2)`，输入框→示例保持 16px 不挤。
- **重心**：`.hero-layout` margin `12vh` → **`10vh`**（加宽后实测仍偏上，下移约 18px；保留"略偏上"手感，不回到钉死正中）。

## 验证

- 前端 `npm test` 10/10、`npm run lint:check`、`npm run build` 全绿。
- 浏览器实测：
  - 标题→输入框 8px、输入框→示例 16px；
  - 阴影 `rgba(16,24,40,0.07) 0px 0px 18px 0px`（对称均匀）；
  - hero 按钮 40×40 圆（50%）、dock 按钮 32×32 圆（50%）——形状一致；
  - hero 宽度 780px（原 680）；组重心从 35% 下移到 31%（标题 20%、输入条 29%、示例底 42%）。

## 尚存说明

- 重心仍保持"略偏上"（用户此前明确不要钉死正中）；若还想更居中，把 `.hero-layout` 的 `10vh` 再降到 `8vh` 即可，一行改动。
