# 2026-09-27 品牌图标落地（预约教室助手）

## 起因

"预约教室助手"产品名确定后，AI 生成并处理了品牌图标（蓝底圆角徽章 + 白色教室门 + 日历 + 绿色对勾，透明底、多尺寸压缩，见仓库根 `品牌图标/`），用户确认方案后替换进产品。

## 改动（`frontend/`）

- **`public/favicon.png`**（= `品牌图标/icon_64.png`，64×64，4.8KB）：浏览器标签页图标。`index.html` 的 `<link rel="icon">` 从 `/favicon.svg` 改为 `/favicon.png`（原 favicon.svg 保留未删，作后备）。
- **`public/brand-icon.png`**（= `品牌图标/icon_128.png`，128×128，14KB）：界面 logo。
- **`src/App.vue`**：顶栏 `.brand-mark` 由"渐变底 + IconCheck 对勾符号"改为 `<img src="/brand-icon.png">`；样式简化为 `width/height 24px + object-fit: contain + 圆角`；删除不再使用的 `IconCheck` 导入。
- **`src/views/LoginView.vue`**：登录页 `.brand-mark` 同样替换为品牌图（26px）；删除 `IconCheck` 导入。

## 验证

- 前端：`npm test` 10/10、`npm run lint:check`、`npm run build` 通过。
- 浏览器：刷新后左上角品牌图正常显示、页面标题"预约教室助手"；网络请求确认 `brand-icon.png` 与 `favicon.png` 均加载成功（`GET ok`）。
