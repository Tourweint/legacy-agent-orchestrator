# 2026-09-27 空态重做：去卡片化、纯文本引导

## 起因

用户整体观感"UI 不够美观"，按先问意见再拍板的节奏：采纳"留白与字体层级承担层级"的方向。空态（新对话首屏）是最抢眼的"不美观"来源——虚线边框卡片 + 渐变图标圆底，像表单不像产品。

## 改动（`frontend/`）

`src/components/EmptyState.vue` 重做：
- **去掉虚线边框卡片**（border dashed + radius-card）与**渐变图标圆底**（`accent-gradient-soft` + 圆底 + glow 阴影）——用户基调"不需要边界、简约大气"；

- **`margin: auto` 垂直居中**：空态在消息区里真正居中（不再是贴顶的卡片），是页面主角。
