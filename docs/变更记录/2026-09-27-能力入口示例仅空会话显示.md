# 2026-09-27 能力入口示例仅在空会话显示

## 起因

用户反馈：发完一次"可以这样说"示例后，后续提问不应再显示这些示例；只有**新对话**（空会话）时才给示例。

## 改动（`frontend/`）

`src/components/ChatPane.vue`：能力入口（"可以这样说（角色）"示例区）的展示条件由 `!pending && !suspended`（空闲/终态都显示）改为 **`!store.hasAnyTurn`（仅空会话显示）**。

行为：
- 新对话 / 点"＋ 新对话"：显示示例（第一次引导）；
- 一旦用户发过任何消息（会话里有轮次）：隐藏，不再重复；
- 恢复历史会话（有轮次）：隐藏。

## 验证

- 前端：`npm test` 10/10、`npm run lint:check`、`npm run build` 通过。
- 浏览器端到端三场景：① 新对话显示"可以这样说"；② 点击示例发送后立即隐藏（真实 chat 链路正常）；③ 恢复历史会话后隐藏。
