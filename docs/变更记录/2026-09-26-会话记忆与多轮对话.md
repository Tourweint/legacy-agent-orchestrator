# 2026-09-26 会话记忆与多轮对话（"它记得住上一句"、"办完还能接着说"）

> **文档性质：变更记录（带日期）**。起因是演示后的体验反馈，两条：
> ① **记忆不持久**——"上一句发这个，下一句发那个，它就记不住了"；
> ② **办完就不能再发**——"事情办完了之后就不能再发了，必须新起一个对话"。

---

## 一、根因：三处叠加，缺一不可

| # | 现象 | 根因（代码位置） |
|---|---|---|
| 1 | 新一轮**完全不知道上一句说了什么** | 一个 chat 任务只承载**一轮**对话：理解层的历史放在 `taskContext.chat.history`，而任务落终态后运行栈即销毁——下一轮从零开始。`startChat()` 每次新建任务，历史是空的 |
| 2 | 办完**输入框消失** | `Composer.vue` 在终态时把输入框整体换成"再办一件"按钮（`:v-if="!terminal"`）——用户想接着说一句，没有入口 |
| 3 | **上一轮的对话内容也没了** | `store.startChat()` 上来就 `_reset()`，清空 `events`/`userMessages`/`result`——同一段对话里的上一条看不到了 |

**性质说明**：这不是"模型记性差"，而是**架构上就没有"会话"这一层**——每句话都是一个孤立的原子任务。修法也不能靠"把提示词写得更恳切"，必须补上会话层。

---

## 二、改了什么

### 1. 引擎侧：会话记忆（新文件 `orchestrator/src/access/conversation-store.js`）

按 `conversationId` 攒每一轮的**结构化摘要**，下一轮作为理解层的历史注入：

```text
recordTurn(conversationId, username, { text, intent, slots, outcome })
historyFor(conversationId, username) → [ {user: 原话}, {assistant: JSON{intent,slots,outcome}} … ]
```

设计取舍（都写进了代码注释，供后续复核）：

| 取舍 | 为什么 |
|---|---|
| 助手侧存**结构化摘要**而不是上一轮的自然语言回复 | 模型需要照看的只是"刚才说的是哪间教室、哪个时段、办成了没有"这些事实；把回复原文塞回去会让它模仿措辞 |
| **挂起轮也要记**（`outcome: INPUT_REQUIRED`） | 用户下一句的"那……"依赖这一轮已经说过的信息（"帮我借数智楼222" → 追问时间 → "那下午吧"） |
| 内存态、TTL 回收（空闲 2h） | A6 不变：会话不跨进程持久化 |
| 每会话 20 轮上限、注入最近 6 轮 | 上下文与内存都不无限涨 |
| **只在同一登录用户内可见** | 他人的 `conversationId` 一律另发新 id：不沿用、不读取、**不覆盖**（`ensure` 遇用户名不符返回 null，`resolveId` 负责换发新 id） |

接入层（`http-server.js`）：`POST /api/chat` 接可选 `conversationId`，响应回 `data.conversationId`；执行前取历史、执行后 `onSuccess` 里留档。契约已回写[对外接口清单](../基线文档/对外接口清单.md) §二.6。

编排层（`task-runner.js`）：`executeChatTask({ text, identity, history })` 把会话记忆铺在 `chat.history` 底部（本任务内的追问历史继续追加在其后），并在返回值里附 `understanding`（本轮意图 + 槽位原话）供留档。

### 2. 前端：从"一次性任务"到"会话 + 多轮"

`stores/task.js` 状态分两层：

- **会话**：`conversationId` + `turns[]`（一段对话里说的每一句都留着）
- **当前轮**：一次任务自己的 `events` / `entriesBySeq` / `result` / `clarify`

**组件只依赖"当前轮"的字段**（`taskId` / `taskStatus` / `events` / `result`…），这些以 getter 代理到 `activeTurn`——所以轨迹面板、结果卡**一行没改**就跟着会话化生效了。

行为变化：

| 之前 | 现在 |
|---|---|
| 说一句 → 清空上一句 → 办完 → 输入框变"再办一件" | 说一句 → **留在对话里** → 办完 → **输入框常驻**，接着说不必重开 |
| 没有会话概念 | `conversationId` 贯穿；对话面板顶部有"新对话"（要重开也随时可以） |
| 追问回复单独成一轮渲染 | 追问回复归入**同一轮**（同一任务），对话流按轮渲染 |

`Composer.vue`：`terminal` 不再隐藏输入框，只改提示文案（"继续说点什么，或接着办下一件……"）。
