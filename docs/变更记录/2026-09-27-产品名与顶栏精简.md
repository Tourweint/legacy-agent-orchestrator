# 2026-09-27 产品名与顶栏精简

## 起因

用户反馈（三条）：
1. 顶部状态徽章（"已办成"带对勾、横在顶栏中间的胶囊）不要显示了；
2. 左上角副标题"每一步都看得见依据"不要，只留主标题；
3. "代办"这个说法不直观（不知道是干啥的）——要突出教室预约功能，改名为"预约教室助手"之类。

## 改动（`frontend/`）

### `src/App.vue`

- **移除顶栏任务状态徽章**：删除 `statusView` computed（运行中/等待输入/已办成/未能办成/已取消/待人工处理全套）与其渲染块、样式（`.status-badge`/`.st-*`/`.status-spin`/`@keyframes spin`）及不再使用的图标导入（`IconSpinner`/`IconFlag`/`IconX`）。SSE 连接指示（`connectionView`）保留。
- **删除副标题**：`.tagline`"每一步都看得见依据"整块删除。
- **产品名**：`校园教室代办` → **`预约教室助手`**（贴合功能：教室预约/查询/退订）。

### `src/views/LoginView.vue` / `index.html`

- 登录页品牌与浏览器标签页标题同步改为"预约教室助手"。

### `src/components/ChatPane.vue`

- 空态引导标题"开始一次代办" → "**开始预约教室**"（同一"代办"措辞，一并改直白）。

## 验证

- 前端：`npm test` 10/10、`npm run lint:check`、`npm run build` 通过。
- 浏览器端到端（localhost:5173，教师 233）：
  - 顶栏只剩"预约教室助手"（无副标题、无状态徽章）；
  - 结构化任务跑至终态：顶部**不再出现"已办成"徽章**，消息区"思考" + 多行结论正常。

## 说明

- SSE 连接指示（"已连接/重连中"）保留——它只在任务进行中显示，不含"打对勾"。
- 右上角身份区（教师 233 / 退出登录）、左侧栏"＋ 新对话"不变。
