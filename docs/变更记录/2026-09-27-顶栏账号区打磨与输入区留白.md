# 2026-09-27 顶栏账号区打磨与输入区底部留白

## 起因

用户两处观感问题：① 右上角"角色 + 用户名 + 退出登录"连排（蓝色角色胶囊 + 下划线链接）像测试页面，不够产品化；② 输入框贴屏幕底边太近，希望底部留白到 16~20px 左右（先问意见，拍板"不整体上挪、只加底部留白"）。

## 改动（`frontend/`）

- **`src/App.vue`** 账号区重做：
  - 角色标签 + 用户名收进**一个浅灰胶囊**（`surface-2` 底、圆角，与连接指示器同体系；角色淡蓝字、用户名深色字）；
  - "退出登录"由下划线文字链接改为**细边框 ghost 按钮**（hover 变浅红提示危险操作）；
  - 顶栏右侧节奏统一：图标按钮 ×3 → 账号胶囊 → 退出按钮。
- **`src/components/ChatPane.vue`**：输入区（dock）底部 padding `var(--space-3)`（12px）→ **`18px`**（用户口径 16~20 左右；顶部仍 8px 保持紧凑）。

## 验证

- 前端：`npm test` 10/10、`npm run lint:check`、`npm run build` 通过。
- 浏览器：顶栏"教师 233"一体胶囊 + 退出登录 ghost 按钮正常、输入框与屏幕底边留出约 18px 稳定间隙。
