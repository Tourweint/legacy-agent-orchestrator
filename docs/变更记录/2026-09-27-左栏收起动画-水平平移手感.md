# 左栏收起动画：内容挤压改为水平平移手感（2026-09-27）

## 背景

用户点出细节：咱们的左栏收起时，内容有一种"被挤压"的感觉——好像从横着变成竖着、被挤没了；而 DeepSeek 的左栏是**水平平移**一样滑出去。

## 根因

原有实现是「grid 轨道塌缩」动画：

- `App.vue` `.views`：`grid-template-columns: 268px minmax(0,1fr)` → `0 minmax(0,1fr)`，轨道宽度动画；
- `ConversationList.vue` `.side`：随轨道一起被压缩，`overflow: hidden` 裁切。

问题有两个：

1. **内容跟着容器一起被横向压缩**——宽度一小于内容所需，`head` 的"＋ 新对话"、分组标签、条目布局全部被迫换行/竖排/收缩，视觉上就是"被挤没了"。
2. **`head`/`list` 上有 `v-if="!collapsed"`**——点击收起的瞬间 Vue 把内容整体卸载，动画期间容器里是空的，连"滑出"的过程都没有。

## 改动（`ConversationList.vue`）

1. **内容层 `.side-inner` 固定为展开宽度 268px**（`position: absolute; top/left/bottom 0; width: 268px`），容器 `.side` 加 `position: relative; overflow: hidden`——轨道塌缩时**内容保持完整不变形**，被容器右缘从右往左裁切 → 视觉上像一块板子水平平移滑出（DeepSeek 同款手感）。
2. **删掉 `head`/`list` 的 `v-if="!collapsed"`**——内容常驻渲染，动画期间才有"滑出/滑入"的过程；收起后的不可见性交给容器 `width: 0 + overflow: hidden + visibility: hidden`（延迟隐藏）处理。
3. `.side` 的 `padding` 移到 `.side-inner`（容器不再有内边距，避免塌缩时 padding 动画干扰）；transition 精简为 `width / border-color / visibility`。
4. **窄屏（≤900px）**：`.side-inner` 回 `static`（容器 `height: auto` 时 absolute 会脱离流导致高度塌陷）；收起仍走 `display: none`。

## 验证

- 前端 `npm test` 10/10、`npm run lint:check`、`npm run build` 全绿。
- 浏览器动画全程采样：展开时 `sideW 1→3→8→15→…→268` 平滑过渡（transition 正常，`--dur-base` 200ms）；**动画全程 `innerW` 恒 268、`itemW` 恒 238（内容完整、无换行/挤压）**，`visibility` 动画结束后延迟隐藏。展开态与收起态均正常。
- 收起后对话区平滑让位（grid 第二列从 979px 扩到全宽，原有行为不变）。

## 尚存说明

- 该手感是"内容保持宽度、被边缘裁切"（容器边界移动），与 DeepSeek"内容整体位移"在视觉上等价（相对运动），实现上无需 JS。
- `--dur-base`（200ms）未改；若后续想更接近 DeepSeek 的从容感，可单独把左栏动画时长调成 `--dur-slow`（240ms），一行改动。
