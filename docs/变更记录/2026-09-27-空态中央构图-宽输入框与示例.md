# 空态中央构图：问候、宽输入框与示例（2026-09-27）

## 背景

用户参考 DeepSeek 网页端（示例图）：空态是"中央问候 + 中央宽输入框 + 输入框下功能按钮"，有对话后输入框才在底部。用户拍板：第一次对话的输入框放中间、宽一点（不扁平）；文案"开始预约教室"改"预约教室从这里开始"；快捷示例第一次放中央输入框下方；中央输入框宽度按视口百分比自适应（约 50%，浏览器窄了自动变窄）；左栏收起要有"动画延长过去"。

## 改动

1. **空态中央构图**（`ChatPane.vue`）：`!hasAnyTurn` 时消息区渲染 `.hero`（垂直+水平居中）——`EmptyState`（图标 + "预约教室从这里开始" + "用一句话说明要办的事"）→ `Composer variant="hero"`（中央宽输入框）→ 示例 chips（"可以这样说（角色）"）在输入框下方。**底部 dock 的示例区移除**（示例只在空态中央出现）；dock 的 `Composer` 改为 `v-if="store.hasAnyTurn"`（有对话后才在底部显示）。发消息后 hero 让位给消息流、输入框回底部。
2. **Composer 加 `variant` prop**（`dock` 默认 / `hero`）：hero 形态 `width: min(50vw, 680px)`（约视口 50%，窄屏自动变窄、上限 680px 防超宽拉散）、内边距 14/18px、圆角 `radius-lg`、输入字号 `text-base`、发送按钮加大——"不扁平、宽一点"。底部 dock 形态不变。
3. **聚焦逻辑**：新增 `heroComposerRef`，`focusComposer()` 按当前形态聚焦（空态→中央实例，对话中→底部实例）；Ctrl/Cmd + K 走它。
4. **左栏收起动画**：`App.vue` 的 `grid-template-columns: 268px ↔ 0` 过渡（200ms）**已存在**（2026-09-27 全屏改造时实现），本轮实测确认"收起时对话区平滑扩到全宽"的效果，未改动。

## 验证

- 前端 `npm test` 10/10、`npm run lint:check`、`npm run build` 全绿。
- 浏览器端到端：空态中央构图（问候→宽输入框 620px≈50vw→示例 chips 在输入框下，底部无输入框）；点示例发消息后 hero 消失、输入框回底部 dock、示例隐藏、消息流/结论正常；左栏收起 grid `268px 971px → 0px 1239px`（动画过渡）再展开复原。

## 尚存说明

- hero ↔ dock 的切换是瞬时 v-if 切换（无位移动画）；若后续要"输入框从中央滑到底部"的过渡，需额外做 FLIP 动画，本轮未做。
- 中央输入框宽度用 `min(50vw, 680px)`：视口 1239 时约 620px；窄屏（<900）左栏变顶部横条，50vw 仍自适应。
