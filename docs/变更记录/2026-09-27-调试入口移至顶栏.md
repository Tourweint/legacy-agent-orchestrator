# 2026-09-27 调试入口移至顶栏

## 起因

用户反馈：调试入口（结构化任务）放在对话区底部显得主页不大气，移到顶部做成设置/工具图标入口。

## 改动（`frontend/`）

- **新增 `src/components/DebugModal.vue`**：调试弹窗（居中遮罩 + 面板：标题"调试入口（结构化任务）"、说明、`DebugTaskPanel`、关闭按钮；点击遮罩或 × 关闭，淡入淡出）。
- **`src/App.vue`**：顶栏右侧新增**终端图标按钮**（`IconTerminal`，title"调试入口（结构化任务）"，位于快捷键 `?` 按钮之前），点击打开调试弹窗；挂载 `<DebugModal :visible="showDebug" @close="…">`。
- **`src/components/ChatPane.vue`**：移除底部 `<details class="debug">` 调试区（含 `.debug` 样式与 `DebugTaskPanel` 导入）——主页底部只剩能力入口、输入框。
- **`src/components/DebugTaskPanel.vue`**：提交成功后 `emit('submitted')`，调试弹窗随即自动关闭，页面直接看任务跑。

## 验证

- 前端：`npm test` 10/10、`npm run lint:check`、`npm run build` 通过。
- 浏览器端到端：顶栏出现调试图标按钮；点开弹窗（标题/说明/textarea/提交/关闭齐全）；提交结构化任务后**弹窗自动关闭**、任务正常跑完（6 条生效预约多行结论）；底部不再有任何调试入口，主页干净。
