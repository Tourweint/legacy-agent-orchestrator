# 输入条居中修复：按钮纯图标与 class 撞名根治（2026-09-27）

## 背景

用户反馈两个问题：
1. **发送按钮**：对话进行中（输入条在底部 dock）时"发送"没居中、位置不对；要求把"发送"两个字取消，只留纸飞机 SVG 图标。
2. **placeholder**："继续说点什么，或接着办下一件……"在输入框里上下间距不一样（不垂直居中）。

排查后发现真正根因是 **CSS class 撞名**，不止是文案问题。

## 根因（重要，后续勿再踩）

Composer 组件根元素 `class="composer dock"`（`:class="variant"`，默认 variant='dock'）——**撞上了 ChatPane 的 `.dock` 容器类**。ChatPane scoped 规则 `.dock[data-v-xxx]`（padding `8px 24px 18px`，顶部 8 / 底部 18 不对称）与 Composer 自己的 `.composer[data-v-xxx]`（padding `6px 6px 6px 12px`）特异性同为 (0,2,0)，ChatPane 样式后注入获胜 → 输入条 padding 被污染成上 8 下 18 → 输入框/按钮整体偏上 10px、"没居中"、上下间距不均。

同理：hero 输入条 `class="composer hero"` 撞 ChatPane 空态容器 `.hero`（`flex-direction: column; gap: 16px`）→ hero 输入条的输入框与按钮被排成**竖列**（输入条高 122px，按钮掉到输入框下方）。

## 改动

1. **`Composer.vue`**：
   - 根元素 class 不再裸用 variant 值：`:class="variant"` → `:class="{ hero: variant === 'hero' }"`——非 hero 时元素只有 `class="composer"`，彻底避开 `.dock` 撞名；hero 形态保留 `.hero` 类（Composer 内部自用）。
   - **按钮统一纯图标**：`.composer .btn .btn-label { display: none; }`（dock 与 hero 都不显示文字，"发送/回复/改口重来"语义由 `aria-label`/`title`/placeholder 承担）；dock 按钮 `padding: 8px` 收窄成 32×32 紧凑色块；hero 按钮保持 40×40 圆形。
   - **输入文字垂直居中**：`.composer .input` 垂直 padding 8px → `padding: 0 4px; line-height: 32px`（原来 8px padding + 默认行高 ~19px 溢出 16px 内容区，文字上 8px / 下 4.8px 不均）；hero input `padding: 0 6px; line-height: 36px`。
   - `.composer.hero` 显式 `margin: 0`（防止 ChatPane `.hero` 的 `12vh auto auto` 兜底作用）。
2. **`ChatPane.vue`**：空态容器 `.hero` 改名 **`.hero-layout`**（模板 + 样式同步）——彻底消除与 Composer hero 形态的撞名，避免 `flex-direction: column` 等规则污染输入条。

## 验证

- 前端 `npm test` 10/10、`npm run lint:check`、`npm run build` 全绿。
- 浏览器实测：
  - dock：composer class 只剩 `composer`、padding `6px 6px 6px 12px`、输入框相对输入条内容区**垂直偏移 0**（上下间距相等）、按钮 32×32 纯图标在右侧与输入框对齐；
  - hero：输入条 `flex-direction: row`、高 70px（原 122px）、按钮 40×40 圆形在输入框**右侧**（不再竖排下方）、margin 0、chips 位置正常；
  - placeholder 文字行高 32/36px 垂直居中。

## 尚存说明

- 按钮文字隐藏后，运行中"改口重来"等状态语义仅靠 placeholder 与 title 提示；若后续要恢复文字，改回 `.btn-label` 显示即可。
- 根因是通用问题：**组件根元素的 class 名不要与父组件的容器类撞名**（scoped 属性会落到子组件根元素上），已在代码注释中标注。
