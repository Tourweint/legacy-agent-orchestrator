# 校园教室 AI 代办系统 —— 超详细使用教程（电脑小白版）

> 写给完全不懂技术的你：跟着一步一步做，就能学会使用这个系统。
> 不需要任何编程知识，会用浏览器、会打字就行。

---

## 写在最前面：这个系统是干什么的？

想象一下：你学校有一个很老的教室预约网站，操作很麻烦，要填很多表格，点很多按钮。

**我们做的这个系统，就是一个"智能助手"**——你只要用大白话告诉它"我要借教室"，它就会自动帮你在那个老网站上完成所有操作，而且会把每一步都告诉你，让你看得明明白白。

**它最大的特点**：
- **不会重复提交**：如果你已经借过了，再说一遍"我要借"，它会告诉你"已经借过了"，不会再借一次
- **每一步都看得见**：它做了什么、为什么这么做，都清清楚楚地显示出来
- **出问题不装懂**：如果网络不好、不确定有没有成功，它会如实告诉你，不会假装成功了

## 一、第一次使用：怎么打开系统

### 第 1 步：确认系统已经启动

这个系统需要在电脑上先启动才能用。如果你是在比赛演示现场，工作人员已经帮你启动好了，直接跳到第 2 步。

如果你是自己在电脑上运行：

1. 找到项目文件夹 `D:\legacy-agent-orchestrator`
2. 双击里面的 `start-all.bat` 文件
3. 会弹出一个黑色窗口，里面会滚动很多文字
4. **耐心等待 30 秒左右**，等文字不再快速滚动了，就说明启动好了
5. **不要关闭那个黑色窗口**，关了系统就停了

### 第 2 步：打开浏览器

1. 双击桌面上的浏览器图标（Chrome、Edge 都可以）
2. 在浏览器最上面的**地址栏**（就是显示网址的那个长条）里，输入：

```
localhost:5173
```

3. 按键盘上的 **回车键**

### 第 3 步：你会看到登录页面

如果一切正常，你会看到一个登录页面，上面写着"校园教室代办"，有账号和密码两个输入框。

> 💡 **小贴士**：如果页面打不开，显示"无法访问此网站"，说明系统还没启动好，再等一会儿，或者看看第 1 步的黑色窗口有没有报错。

## 二、登录系统

### 第 1 步：输入账号

1. 用鼠标点击"账号"输入框（就是那个写着"请输入用户名"的空白框）
2. 输入你的账号

**演示账号（比赛时用这个）**：

| 身份 | 账号 | 密码 |
|---|---|---|
| 老师 | `233` | `233` |
| 学生 | `abc` | `abc` |

> ⚠️ **注意**：
> - 账号和密码都要**完全一样**，包括大小写（这里都是小写和数字，没问题）
> - 老师账号可以借整间教室，学生账号只能占座位，不能借整间教室
> - 如果你是学生，用 `abc` 登录；如果你是老师，用 `233` 登录

### 第 2 步：输入密码

1. 用鼠标点击"密码"输入框
2. 输入密码（和账号一样，老师是 `233`，学生是 `abc`）

### 第 3 步：点击登录

1. 用鼠标点击蓝色的"登录"按钮
2. 等待 1-2 秒

### 第 4 步：登录成功

如果登录成功，你会进入对话页面，左边是会话列表，右边是聊天区域。

> 💡 **小贴士**：如果登录失败，页面上会显示红色的错误提示。最常见的原因是账号或密码输错了，仔细检查一下重新输入。

## 三、认识界面：每个按钮是干什么的

登录成功后，你会看到这样的界面：

```
┌──────────┬─────────────────────────────────┐
│  会话列表  │  顶部：系统名称 · 主题 · 退出     │
│          ├─────────────────────────────────┤
│  · 对话1  │                                 │
│  · 对话2  │        聊天区域                  │
│  · 对话3  │     （你和系统的对话在这里）      │
│          │                                 │
│ [+新对话] │                                 │
│          ├─────────────────────────────────┤
│          │  输入框  [发送按钮]              │
└──────────┴─────────────────────────────────┘
```

### 左边：会话列表

- **会话**就是"一段对话"的意思。你可以把它想象成微信的聊天列表。
- 点击 **"+新对话"** 可以开始一段新的对话
- 点击历史对话可以回到之前的对话
- 不同的对话之间互不影响

### 中间/右边：聊天区域

- 这里显示你和系统的对话内容
- **你说的话**显示在右边（蓝色气泡）
- **系统的回复**显示在左边（白色卡片）
- 系统的回复包括：**结论**（大字显示）和**思考过程**（可以展开看细节）

### 底部：输入框

- 在这里输入你想让系统帮你做的事
- 输入完后点击右边的蓝色"发送"按钮，或者按键盘的回车键
- 输入框上面有一些**蓝色的小按钮**，是常用的快捷指令，点击一下就自动填好了，不用自己打字

### 顶部：用户信息

- 显示当前登录的用户名和角色（老师/学生）
- 点击"退出登录"可以退出当前账号

## 四、功能一：帮我借一间教室（老师用）

> ⚠️ **注意**：只有老师账号可以借整间教室。学生账号请直接看[第九节：学生怎么占座位](#九功能六学生怎么占座位)。

### 第 1 步：在输入框里说你要借教室

在底部的输入框里，用大白话输入你要做的事。比如：

```
帮我借明天下午数智楼222
```

或者：

```
我想借下周三上午的数智楼123，开班会用
```

> 💡 **小贴士**：
> - 怎么说都行，系统能听懂大白话
> - 要说清楚三件事：**借哪间教室**、**哪一天**、**什么时间**
> - 如果没说清楚，系统会问你，你再补充就行

### 第 2 步：点击发送

输入完后，点击右边的蓝色"发送"按钮，或者按键盘的回车键。

### 第 3 步：等待系统处理

发送后，你会看到系统正在"思考"（显示一个加载动画）。这个过程通常需要 **3-10 秒**，请耐心等待。

系统在后台会自动做这些事（你不用管，它自己会做）：
1. 查一下这间教室存在不存在
2. 查一下这个时段有没有被别人借走
3. 查一下你自己有没有已经借过这个时段（避免重复）
4. 查一下这间教室有没有在维修
5. 如果一切正常，就帮你提交预约

### 第 4 步：看到结果

处理完成后，系统会显示结果。有几种可能：

#### ✅ 情况一：借成功了

你会看到绿色的"已办成"，下面写着：

```
已为您办妥：数智楼 222（预约 #184，2026-10-01 14:00–16:00）
```

这就说明借成功了！你可以在老系统的"我的预约"里看到这条记录。

#### ⚠️ 情况二：这个时段已经被借走了

你会看到红色的"没办成"，下面写着：

```
无法办理：该时段已有安排
```

这说明这个时段已经被别人借了，你需要换一个时间或者换一间教室。

#### ℹ️ 情况三：你已经借过了（重复提交）

你会看到绿色的"已办成"，下面写着：

```
已为您办妥：此事此前已办成（预约 #180，2026-10-01 14:00–16:00），未重复提交。
```

这说明你之前已经借过这个时段了，系统**不会重复借**，而是如实告诉你"已经借过了"。这是系统的智能之处——不会因为你多说了一遍就多借一次。

#### ❓ 情况四：系统问你问题

如果你没说清楚（比如没说哪间教室），系统会问你：

```
请问您想借哪间教室？
```

你直接在输入框里回答就行，比如：

```
数智楼123
```

然后系统会继续帮你处理。

## 五、功能二：查一下教室有没有空

这个功能老师和学生都能用。

### 操作步骤

1. 在输入框里输入：

```
查一下明天上午数智楼123有没有空
```

2. 点击发送
3. 等待 3-5 秒
4. 看到结果

### 可能的结果

- **有空**："数智楼 123 在 2026-10-01 08:00–12:00 空闲，可以预约"
- **没空**："数智楼 123 在该时段已有预约（预约 #XXX），不可用"
- **维修中**："数智楼 123 在该时段处于检修期，不可用"

> 💡 **小贴士**：查询只是看看，不会真的借。如果你查完想借，直接再说一句"那帮我借了吧"就行，系统记得你刚才查的是哪间教室。

## 六、功能三：看看我借了哪些教室

这个功能老师和学生都能用。

### 操作步骤

1. 在输入框里输入：

```
查一下我的预约
```

或者：

```
我最近借了哪些教室？
```

2. 点击发送
3. 等待 3-5 秒
4. 看到你名下的所有预约列表

### 结果示例

系统会列出你所有的预约，每条包括：
- 预约编号（比如 #180）
- 教室名称（比如 数智楼 123）
- 日期和时间（比如 2026-10-01 14:00–16:00）
- 状态（有效/已取消/已过期）

## 七、功能四：我不想借了，帮我退掉

这个功能老师和学生都能用，但只能退**你自己名下**的预约。

### 方法一：用预约编号退（推荐，最准确）

如果你知道预约编号（在"我的预约"里能看到），直接说：

```
帮我退掉预约 #180
```

### 方法二：用教室和时间退

如果你不记得编号，可以说：

```
取消我明天下午数智楼222的预约
```

### 操作步骤

1. 在输入框里输入上面的话
2. 点击发送
3. 等待 3-5 秒
4. 看到结果

### 可能的结果

- ✅ **退成功了**："已撤销：数智楼 123（预约 #180，2026-10-01 14:00–16:00）"
- ❌ **不是你的预约**："预约 #180 不是您名下的记录，无法撤销"（系统不会让你退别人的预约）
- ❌ **找不到预约**："未找到预约 #180"（检查一下编号是不是输错了）

## 八、功能五：帮我改个时间

这个功能老师和学生都能用，只能改**你自己名下**的预约。

### 操作步骤

1. 在输入框里输入：

```
把预约 #180 改到后天下午
```

或者：

```
我明天下午数智楼222的预约，改成下周三上午
```

2. 点击发送
3. 等待 5-10 秒（改期比借教室慢一点，因为要做两步操作）
4. 看到结果

### 系统是怎么改期的（你不用管，了解一下就行）

改期的时候，系统会**先帮你借新的时间，再退掉旧的时间**。这样做的好处是：
- 如果新时间没借上，旧的预约**还在**，不会两头空
- 如果新的借上了但旧的退不掉，系统会如实告诉你，让你找管理员处理，**不会假装成功**

### 可能的结果

- ✅ **改期成功**："已改期：数智楼 123 从 2026-10-01 14:00–16:00 改为 2026-10-03 14:00–16:00（新预约 #185）"
- ⚠️ **新时间没空**："新时段已有安排，原预约（#180）未改动"（你的原预约还在，不用担心）
- ⚠️ **需要人工处理**："新预约已创建（#185），但旧预约（#180）撤销失败，请联系管理员"（这种情况很少见，如果遇到了找管理员帮忙退一下旧的就行）

## 九、功能六：学生怎么占座位

> ⚠️ **注意**：只有学生账号可以占座位。老师账号不能占座位，只能借整间教室。

### 什么是"占座位"

占座位和借教室不一样：
- **借教室**：把整间教室包下来（只有老师能做）
- **占座位**：在教室内预约一个具体的座位（学生自习用）

### 座位号怎么看

座位号的格式是 **"排-列"**，比如：
- `2-3` = 第 2 排第 3 个座位
- `1-1` = 第 1 排第 1 个座位

### 操作步骤

1. 用学生账号（`abc/abc`）登录
2. 在输入框里输入：

```
帮我占今天下午数智楼222的2-3座位
```

或者：

```
预约数智楼222的第2排第3个座位，明天上午
```

3. 点击发送
4. 等待 3-10 秒
5. 看到结果

### 重要提醒

座位预约有一个限制：**只能提前 24 小时预约**。

也就是说：
- ✅ 今天约明天的座位，可以
- ❌ 今天约下周的座位，不行

如果你约的时间超过 24 小时，系统会告诉你：

```
座位预约只能提前 24 小时，请选择更近的时段
```

### 可能的结果

- ✅ **占成功了**："已为您预约：数智楼 222 座位 2-3（2026-09-28 15:00–17:00）"
- ❌ **座位不存在**："未找到座位 2-3（数智楼 222）"（检查一下座位号是不是输错了）
- ❌ **超过 24 小时**："座位预约只能提前 24 小时，请选择更近的时段"
- ❌ **被别人占了**："该座位在该时段已被预约"

## 十、怎么看系统"思考过程"

系统的每一次回复，除了告诉你最终结果，还会记录它"思考"的每一步。你可以展开看看，系统到底做了什么。

### 怎么展开

在系统的回复卡片上，你会看到一个写着"思考过程"或者"为什么是这个结果"的区域，旁边有一个小箭头（▶）。

1. 用鼠标点击那个小箭头
2. 箭头会变成向下（▼），同时展开详细内容
3. 再点一下就收起来

### 你会看到什么

展开后，你会看到系统做的每一步，比如：

```
✓ 找到了这间教室（数智楼 222）
✓ 收集到：这些座位在这段时间的占用情况
✓ 收集到：全量预约记录（跨身份查看）
✓ 收集到：我名下的预约
✓ 收集到：这间教室的检修安排
✓ 判定：这间教室现在可以预约
✓ 判定：我没有重复提交过同一时段
✓ 判定：这个时段是空的
✓ 判定：这间教室这段时间不在检修
→ 决策：所有前置条件满足，提交预约
✓ 提交预约成功
```

每一步都用**大白话**写清楚了，不用懂技术也能看明白。

### 为什么要看思考过程

- **放心**：你能看到系统确实做了该做的检查，不是随便给你一个结果
- **明白**：如果没办成，你能看到是哪一步出了问题（比如"这个时段不是空的"）
- **可信**：每一步都有记录，出了问题能查清楚是怎么回事

## 十一、高级小技巧

### 技巧 1：一次说多间教室

你可以一次说多间教室，系统会按顺序帮你都借了：

```
帮我借明天下午数智楼123和222
```

### 技巧 2：接着上一句说

在同一段对话里，你可以接着上一句说，系统记得你之前说的内容：

```
你：帮我借明天下午数智楼222
系统：已为您办妥...
你：那改成后天下午
系统：（系统记得是数智楼222，直接帮你改期）
```

### 技巧 3：用快捷按钮

输入框上面有一些蓝色的小按钮，是常用的快捷指令。点击一下就自动填好了，不用自己打字。

### 技巧 4：不想等了可以取消

如果系统正在处理中（显示加载动画），你改变主意了不想办了：
1. 点击输入框旁边的"停止"按钮（或者按键盘的 Esc 键）
2. 如果系统还没开始真正提交预约，会立即停止
3. 如果系统已经把预约请求发出去了，就不能取消了（因为已经在老系统里生成记录了），系统会继续执行完并告诉你结果

> 💡 **为什么发出去了就不能取消？** 因为预约请求已经发到老系统了，老系统可能已经生成了记录。这时候如果假装"取消了"，但老系统里还有记录，就会出问题。所以系统会如实告诉你"已经发出去了，不能取消"，这是负责任的做法。

### 技巧 5：多段对话

如果你同时在办几件事，可以开多段对话，互不干扰：
- 对话 1：借教室
- 对话 2：查我的预约
- 对话 3：退预约

点击左边的"+新对话"就可以开新的一段。

## 十二、遇到问题怎么办

### 问题 1：页面打不开，显示"无法访问此网站"

**可能原因**：系统还没启动好，或者启动失败了。

**解决方法**：
1. 看看那个黑色的启动窗口还在不在，有没有报错（红色的文字）
2. 如果窗口关了，重新双击 `start-all.bat`
3. 等 30 秒再刷新页面试试

### 问题 2：登录失败，显示"账号或密码不正确"

**可能原因**：账号或密码输错了。

**解决方法**：
- 老师账号：`233` / `233`
- 学生账号：`abc` / `abc`
- 注意都是小写，不要有空格

### 问题 3：登录失败，显示"存量系统返回异常"

**可能原因**：老系统（8080 端口）没启动好，或者 Redis/数据库没启动。

**解决方法**：
1. 看看黑色启动窗口里有没有报错
2. 确认所有服务都启动了（MySQL、Redis、老系统、引擎、前端）
3. 重启 `start-all.bat`

### 问题 4：输入自然语言后，显示"理解层不可用"

**可能原因**：没有配置大模型密钥（DASHSCOPE_API_KEY）。

**解决方法**：
- 自然语言对话需要大模型支持，如果没配置密钥，就不能用自然语言
- 但是**结构化任务入口始终可用**（可以通过 API 提交任务，不需要大模型）
- 比赛演示时，工作人员会配置好密钥，不用担心
- 如果是自己测试，可以找管理员要一个密钥，或者用结构化方式提交任务

### 问题 5：系统一直在"思考"，半天不出结果

**可能原因**：网络慢，或者老系统响应慢。

**解决方法**：
1. 耐心等一下，通常 10 秒内会出结果
2. 如果超过 30 秒还没结果，可以点击"停止"按钮，然后重新发送一次
3. 如果每次都很慢，看看老系统是不是卡住了

### 问题 6：显示"不确定，已登记人工处理"

**可能原因**：系统发出了预约请求，但没收到响应（比如网络断了一下），不确定到底有没有成功。

**解决方法**：
1. 这是系统的**安全机制**——不确定的时候不会假装成功
2. 你可以去老系统的"我的预约"里看看，到底有没有成功
3. 如果成功了，就不用管了；如果没成功，再重新借一次
4. 如果有问题，找管理员帮忙查一下

### 问题 7：我是学生，想借整间教室，系统不让

**这是正常的**：整间教室只能由老师预约，学生只能占座位。

如果你是学生但需要借整间教室，请找老师帮忙，或者联系管理员。

### 问题 8：我想退预约，系统说"不是您名下的记录"

**这是正常的**：你只能退自己名下的预约，不能退别人的。

检查一下预约编号是不是输错了，或者是不是登错账号了。
