## 二、看板内容（数据全部来自已有实测，**不新造数字**）

### 板块 1：故障场景复跑表（核心）

> 来源：`../实验/2026-09-25-混沌实验-D0-D6.md`

| 场景 | 注入的故障 | 三次复跑终态 | 一致性 |
|---|---|---|---|
| 撤防对照（基线） | 无 | 办成 / 办成 / 办成 | ✓ |
| 超时但未写入 | 出站超时 | 办成 ×3 | ✓ |
| **响应丢失（半成功）** | 真转发落库后丢响应 | 办成 ×3（查证命中，未重复提交） | ✓ |
| 冲突：其实是自己已成功 | 返回冲突码 | 办成 ×3（判为幂等命中） | ✓ |
| 冲突：真的被别人占了 | 真实占用 | 有依据拒绝 ×3 | ✓ |
| 权限错判（假成功防线） | 越权返回 | 失败 ×3（**没有把越权当成功**） | ✓ |
| 补偿失败登记 | 撤销再撤销 | 待人工介入 ×3（如实登记） | ✓ |
| 只读故障不影响写入 | 读接口故障 | 办成 ×3 | ✓ |

**一句话讲法**："8 类故障，每类跑 3 次，结果一致——**能复现的容错才算容错**。"

## 三、呈现形式（两种都要）

| 形式 | 用途 | 规格 |
|---|---|---|
| **前端"成果"页** | 视频第 10 幕镜头 | 一屏放下板块 1/2/3/4/5；数字大、可读；不做动画 |
| **文档版成果页** | 答辩被追问时调出 | 每个数字给出**来源链接**与**复核方式**（可复跑） |

**共同纪律**：
- 每个数字都能指到来源（实验档 / 复核章节），**没有来源的数字不上板**。
- 不写"提升了 X%"这类无法验证的表述。
- 失败类数据照实写（例如"错误样本本轮为 0，阈值下界未复现"）——**诚实比漂亮更有说服力**。
