## 三、结构化任务测试数据（调试入口）

> 使用方式：前端页面底部展开「调试入口（结构化任务）」，将 JSON 粘贴到文本框，点击「提交结构化任务」。
> 所有时间均为 
>
> **UTC 时间**
>
> ，必须带 
>
> `Z`
>
>  后缀。北京时间 = UTC + 8 小时。

### 3.1 借教室 — 正常成功路径

#### 用例 S1：教师借数智楼 123（未来空闲时段）



```
{

&#x20; "intentId": "borrow-classroom",

&#x20; "identity": "TEACHER",

&#x20; "slot": {

&#x20;   "start": "2026-10-15T05:00:00Z",

&#x20;   "end": "2026-10-15T07:00:00Z"

&#x20; },

&#x20; "resources": \[{ "classroom": { "classroomId": 5 } }]

}
```



* 北京时间：2026-10-15 13:00–15:00

* 预期：终态 DONE，创建预约成功，证据链约 12–15 条

* 验证点：P1 收集事实 → P2 判定（教室存在 / 启用 / 无冲突 / 无检修）→ P3 提交 → P4 查证

#### 用例 S2：学生借数智楼 222



```
{

&#x20; "intentId": "borrow-classroom",

&#x20; "identity": "STUDENT",

&#x20;   "end": "2026-10-20T08:00:00Z"

&#x20; },

&#x20; "resources": \[{ "classroom": { "classroomId": 4 } }]

}
```



* 北京时间：2026-10-20 14:00–16:00

* 预期：终态 DONE

* 验证点：学生身份权限域，使用 STUDENT 身份调用预约接口

#### 用例 S3：借电信楼 111（跨教学楼）

### 3.2 借教室 — 幂等查证（核心创新点）

#### 用例 S4：重复提交同一预约（幂等命中）

> 先执行 S1 创建预约，然后立即用
>
> **完全相同的参数**
>
> 再次提交。



```
{

&#x20; "intentId": "borrow-classroom",

&#x20; "identity": "TEACHER",

&#x20; "slot": {

&#x20;   "start": "2026-10-15T05:00:00Z",

&#x20;   "end": "2026-10-15T07:00:00Z"

&#x20; },

&#x20; "resources": \[{ "classroom": { "classroomId": 5 } }]

}
```



* 预期：终态 DONE，结论为 "此事此前已办成（预约 #XXX），未重复提交"

* 验证点：


  * P2 阶段 P-NOT-ALREADY-MINE 命题判定为 "本人已预约"

  * 不调用提交接口（无写操作）

  * 证据链中有 "幂等命中" 记录

  * 存量系统中预约数量不增加


### 3.4 边界条件与异常测试

#### 用例 S8：不存在的教室 ID



```
{

&#x20; "intentId": "borrow-classroom",

&#x20; "identity": "TEACHER",

&#x20; "slot": {

&#x20;   "start": "2026-10-20T05:00:00Z",

&#x20;   "end": "2026-10-20T07:00:00Z"

&#x20; },

&#x20; "resources": \[{ "classroom": { "classroomId": 999 } }]

}
```



* 预期：终态 FAILED，结论为 "教室不存在"

* 验证点：P-CLASSROOM-EXISTS 命题判定失败

#### 用例 S9：无时区的时间字符串（应被拒绝）



```
{

&#x20; "intentId": "borrow-classroom",

&#x20; "identity": "TEACHER",

&#x20; "slot": {

&#x20;   "start": "2026-10-20T13:00:00",

&#x20;   "end": "2026-10-20T15:00:00"

&#x20; },

&#x20; "resources": \[{ "classroom": { "classroomId": 5 } }]

}
```



* 预期：HTTP 400，错误信息提示时间格式必须带时区

* 验证点：P1-4 严格 UTC 校验生效

#### 用例 S10：超大请求体（应被拒绝）

> 在 JSON 中添加一个超长字符串字段（>64KB），或用 curl 发送超大 body。



* 预期：HTTP 413 Payload Too Large

* 验证点：P1-3 请求体上限生效

#### 用例 S11：未知意图



```
{

&#x20; "intentId": "unknown-intent",

&#x20; "identity": "TEACHER",

&#x20; "slot": { "start": "2026-10-20T05:00:00Z", "end": "2026-10-20T07:00:00Z" },

&#x20; "resources": \[{ "classroom": { "classroomId": 5 } }]

}
```



* 预期：终态 UNRESOLVED 或 FAILED，任务不会悬空

* 验证点：P1-1 异步异常收敛生效，任务有确定终态

## 十、故障排查



| 现象                | 可能原因                    | 解决方法              |
| ----------------- | ----------------------- | ----------------- |
| 编排引擎启动失败          | 存量系统未启动 / Redis 未启动     | 先启动存量系统和 Redis    |
| 自然语言入口返回 "理解层不可用" | 未设置 DASHSCOPE\_API\_KEY | 设置环境变量后重启编排引擎     |
| 存量系统登录返回 401      | Redis 未启动               | 启动 Redis 后重启存量系统  |
| 前端页面空白            | 编排引擎未启动 / 端口被占用         | 检查 8090 端口，重启编排引擎 |
| SSE 无事件推送         | 任务已终态 / 网络问题            | 检查任务状态，刷新页面       |
| 借教室返回 "教室不存在"     | classroomId 错误          | 参考第二章教室数据         |
| 时间格式错误            | 未带 Z 后缀                 | 使用 UTC 时间，必须带 Z   |
